Array Queue Operations & Complexity

Operation Array Method Time Complexity Behavior
enqueue() push() O(1) Appends to the REAR of queue
dequeue() shift() O(n) Removes FRONT; shifts remaining items
peek() queue[0] O(1) Inspects FRONT without removal
isEmpty() length === 0 O(1) Direct length comparison

*Note: shift() runs in O(n) because JavaScript must reindex all remaining elements.
